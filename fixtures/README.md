# Generated test fixtures

These synthetic PDFs were generated by OpenPDF's fixture builder and are
redistributable under the repository license. Names/signatures are test data.
No private signing key or credential is included.

- forms.pdf: three pages with text, multiline, checkbox, radio, combo, list,
  readonly and signature fields.
- edited.pdf: persisted form values, nine native annotation types and a typed
  transparent signature appearance on page three.
- signed.pdf / signed-twice.pdf: self-signed P-256 signatures, with the second
  signature appended incrementally.
- tampered.pdf: deliberately altered signed bytes; verification must fail.
- 500-pages.pdf: synthetic large page-count navigation fixture.
- pdfium-forms.png: an actual PDFium rendering.

Regenerate using `openpdf --validate-fixtures fixtures`. This generates a new
random test certificate each time; binary files and certificate fingerprints
are not deterministic golden vectors. The command does not access the production
identity profile or save its ephemeral test private key.
